miniMDM Quick Reference
Records

Create, edit, and delete records from the object list. Deleted records are soft-deleted — hidden from the list but not removed. Use Show deleted (the number in brackets is how many it adds to the current tab) to view them; their history page allows recovery via Revert.

Lifecycle states

Every record is Active (the golden record), Draft (pending approval), or Retired. Editing an active record creates a draft alongside it — the active record is unchanged until a Publisher approves. Publish and Retire require Publisher or Admin role.

On an object's list page, each state tab shows how many records it holds (visible to everyone with read access).

The number beside each object in the sidebar is its count of active records. Publishers and Admins also see a blue pill with the number of pending drafts, and a Pending link in the top bar that opens the review queue.

Source & provenance

Records can carry optional provenance: source system (e.g. ERP, CRM) and a source ID linking to the originating system's identifier. Source systems can also push records directly via the inbound webhook API.

History & Revert

Every change is saved as a new version. Click History on any record to see all versions, then Revert to restore a previous one. Reverts are versioned and audited.

Reason for change

The Reason field on create, edit, and delete forms is stored in the audit log. For some objects it is mandatory — the form will show a red asterisk.

Import & Export

Import from CSV, TSV, or JSON via the Tools menu. Insert only always adds a new record; Upsert on <attribute> updates matching records. Not sure of the column names? Click Need a template? in the import dialog to download one, optionally with an example row. Export the current view via the same menu.

Audit log

All data changes and auth events (login, logout, user management) are recorded in the audit log (admin only). Filter by schema, object, action, or username.

Access control

Viewer · read-only  |  Editor · create, update, delete  |  Publisher · also publish drafts & retire records  |  Admin · full access. Roles are granted per schema.
